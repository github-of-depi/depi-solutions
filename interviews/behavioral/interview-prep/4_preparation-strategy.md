# Стратегия подготовки

---

## Технические навыки по грейдам

Что реально проверяют (и что НЕ нужно зубрить) на каждом уровне.

| **Грейд** | **Что проверяют** | **Что можно не знать** |
|-----------|-------------------|------------------------|
| **Junior** | Базовый JS, HTML/CSS, Git, базовый React | Системный дизайн, архитектурные трейдоффы |
| **Middle** | Фреймворк, умение писать код, SQL, HTTP | Трейдоффы микросервисов, сложная архитектура |
| **Senior** | Кэширование, шардирование, оптимизация БД, Code Review | Редкие алгоритмы, байт-код V8, детали HashMap |
| **Tech Lead** | Декомпозиция, работа с требованиями, конфликты в команде | Конкретные фреймворки могут знать средне |

> Уточняйте на собеседовании, что реально проверяют для конкретной позиции. Не учите лишнего.

**Что проверяют реально (вместо шаблонных вопросов):**
- Проектирование системы (дают задачу спроектировать архитектуру)
- Code review (показывают кусок кода — найти проблемы)
- Инженерное мышление (смотрят как рассуждает, а не помнит ли ответ)
- Работа с SQL на практике, а не теория
- Аргументация позиции (может ли обосновать решение)

---

## Системный подход

1. **Таблица ошибок** — после каждого собеседования записывайте, на чём провалились. Не повторяйте.
2. **Таблица-календарь** — с датами, компаниями, впечатлениями, условиями. Помогает сравнивать офферы.
3. **Шпаргалка «вопрос-ответ»** — свой файл, учите по одному вопросу в 1–2 дня, не зубрите «базы».
4. **Мок-собеседования** — с коллегами или через специальные сервисы. Снижают тревогу.

## Что изучать

- Найдите пак типовых вопросов для вашего уровня и проработайте.
- Решайте алгоритмические задачи регулярно (LeetCode Medium для middle+).
- Практикуйте задачи на чистый JS, не на фреймворк.
- Прокачивайте рассуждение вслух — это отдельный навык.
- Рассказывайте о самообразовании: последняя книга, блог, конференция, новая технология.
- Будьте готовы объяснить, что читаете, смотрите, какие технологии интересуют прямо сейчас.

## Анти-советы

> Что делать НЕ нужно

- ❌ **Не репетируйте ответы дословно** — если спросят не по плану, начнёте нервничать.
- ❌ **Не ищите «слитые базы вопросов»** конкретных компаний — интервьюеры знают про них и меняют формулировки.
- ❌ **Не платите за базы задач** — они обесценятся, как только компания проведёт ротацию.
- ❌ **Не пытайтесь проскочить на заученных ответах** без понимания — на работе это вскроется.
- ❌ **Не перегружайте резюме** — уберите нерелевантное. С мидла спросят за каждое слово.
- ❌ **Не спешите в крупные компании** — отложите на 2–3 недели, набейте руку на других.
- ❌ **Не токсичьте о прошлых работодателях** — красная линия. Говорите через уроки и рост.
- ❌ **Не отчаивайтесь** — 300–600 откликов до первого оффера — это нормальная практика на рынке. Это марафон, не спринт.

## Что ценят работодатели (помимо хардов)

| **Качество** | **Почему важно** |
|-------------|-----------------|
| **Проактивность** | Не ждёт задач — предлагает решения |
| **Ответственность** | Можно доверить часть бизнеса |
| **Адаптивность** | Быстро входит в новый контекст |
| **Командность** | Работает с другими, а не один |
| **Самообучение** | Растёт сам, не тянет команду назад |
| **Структурность речи** | Умеет ясно и кратко объяснять |
| **«Горящие глаза»** | Энтузиазм, подкреплённый аргументами |

> **Харды открывают дверь, софты — пускают внутрь.**
