## Что такое HTML и для чего он используется?

HTML (HyperText Markup Language) — стандартный язык разметки, описывающий структуру и содержимое веб-страниц с помощью тегов. Браузер интерпретирует разметку и отображает её пользователю. HTML не является языком программирования — он не содержит логики, только семантическую структуру документа.

## Что такое Doctype и зачем он нужен?

`<!DOCTYPE html>` — объявление в начале документа, сообщающее браузеру, что страница написана по стандарту HTML5. Без него браузер переключается в quirks mode (режим совместимости), в котором некоторые CSS-свойства работают иначе и отображение становится непредсказуемым. Это всегда первая строка любого HTML-документа.

## Что такое семантика в HTML?

Семантика — это использование тегов по их смысловому назначению. Семантические теги передают смысл содержимого не только браузеру, но и поисковым системам и вспомогательным технологиям (скринридерам). Вместо безликого `<div>` используются теги со значением: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`, `<figure>`, `<figcaption>`, `<time>`.

```html
<main>
  <article>
    <header><h1>Заголовок статьи</h1></header>
    <section>...</section>
    <footer>Автор: Иван</footer>
  </article>
  <aside>Похожие статьи</aside>
</main>
```

## Чем отличаются блочные элементы от строчных?

**Блочные** (`<div>`, `<p>`, `<h1>`–`<h6>`, `<section>`) — начинаются с новой строки, занимают всю доступную ширину, допускают явное задание `width` и `height`. **Строчные** (`<span>`, `<a>`, `<strong>`, `<em>`) — располагаются в потоке текста, не допускают произвольных вертикальных отступов. В CSS это поведение управляется свойством `display`.

```html
<div>Блочный — занимает всю строку</div>
<span>Строчный</span> <span>— стоит рядом</span>
```

## Для чего нужен атрибут alt у изображения?

`alt` задаёт альтернативный текст для `<img>`: отображается когда изображение не загрузилось, и зачитывается скринридерами для людей с нарушениями зрения. Пустое значение `alt=""` сигнализирует вспомогательным технологиям, что изображение декоративное и его следует проигнорировать.

```html
<!-- Информативное изображение -->
<img src="avatar.jpg" alt="Фото разработчика Ивана" />

<!-- Декоративное — скринридер пропустит -->
<img src="divider.svg" alt="" />
```

## Что такое мета-теги и что описывается в теге head?

Мета-теги (`<meta>`) содержат служебные метаданные о документе: кодировку, описание для поисковиков, настройки отображения на мобильных устройствах. Тег `<head>` — контейнер для всей служебной информации, которая не отображается на странице напрямую: `<title>`, `<meta>`, `<link>`, `<style>`, `<script>`.

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta name="description" content="Описание страницы для поисковиков" />
  <title>Заголовок вкладки браузера</title>
  <link rel="stylesheet" href="styles.css" />
</head>
```

## Для чего используется тег label?

`<label>` связывает текстовое описание с элементом формы, улучшая доступность и удобство использования. При клике на `<label>` фокус переходит на связанный элемент. Связь устанавливается атрибутом `for`, совпадающим с `id` инпута, либо вложением инпута внутрь самого `<label>`.

```html
<!-- Через атрибут for -->
<label for="email">Email:</label>
<input type="email" id="email" name="email" />

<!-- Через вложение -->
<label>
  Пароль:
  <input type="password" name="password" />
</label>
```
