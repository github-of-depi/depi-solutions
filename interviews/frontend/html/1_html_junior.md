## Что такое HTML и для чего он используется?

HTML (HyperText Markup Language) — стандартный язык разметки, описывающий структуру и содержимое веб-страниц с помощью тегов. Браузер интерпретирует разметку и отображает её пользователю. HTML не является языком программирования — он не содержит логики, только семантическую структуру документа.

## Что такое Doctype и зачем он нужен?

`<!DOCTYPE html>` — объявление в начале документа, сообщающее браузеру, что страница написана по стандарту HTML5. Без него браузер переключается в quirks mode (режим совместимости), в котором некоторые CSS-свойства работают иначе и отображение становится непредсказуемым. Это всегда первая строка любого HTML-документа.

## Что такое семантика в HTML?

Семантика — это использование тегов по их смысловому назначению. Семантические теги передают смысл содержимого не только браузеру, но и поисковым системам и вспомогательным технологиям (скринридерам). Вместо безликого `<div>` используются теги со значением: `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, `<footer>`, `<figure>`, `<figcaption>`, `<time>`.

```html
<main>
  <article>
    <header><h1>Заголовок статьи</h1></header>
    <section>...</section>
    <footer>Автор: Иван</footer>
  </article>
  <aside>Похожие статьи</aside>
</main>
```

## Чем отличаются блочные элементы от строчных?

**Блочные** (`<div>`, `<p>`, `<h1>`–`<h6>`, `<section>`) — начинаются с новой строки, занимают всю доступную ширину, допускают явное задание `width` и `height`. **Строчные** (`<span>`, `<a>`, `<strong>`, `<em>`) — располагаются в потоке текста, не допускают произвольных вертикальных отступов. В CSS это поведение управляется свойством `display`.

```html
<div>Блочный — занимает всю строку</div>
<span>Строчный</span> <span>— стоит рядом</span>
```

## Для чего нужен атрибут alt у изображения?

`alt` задаёт альтернативный текст для `<img>`: отображается когда изображение не загрузилось, и зачитывается скринридерами для людей с нарушениями зрения. Пустое значение `alt=""` сигнализирует вспомогательным технологиям, что изображение декоративное и его следует проигнорировать.

```html
<!-- Информативное изображение -->
<img src="avatar.jpg" alt="Фото разработчика Ивана" />

<!-- Декоративное — скринридер пропустит -->
<img src="divider.svg" alt="" />
```

## Что такое мета-теги и что описывается в теге head?

Мета-теги (`<meta>`) содержат служебные метаданные о документе: кодировку, описание для поисковиков, настройки отображения на мобильных устройствах. Тег `<head>` — контейнер для всей служебной информации, которая не отображается на странице напрямую: `<title>`, `<meta>`, `<link>`, `<style>`, `<script>`.

```html
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <meta name="description" content="Описание страницы для поисковиков" />
  <title>Заголовок вкладки браузера</title>
  <link rel="stylesheet" href="styles.css" />
</head>
```

## Для чего используется тег label?

`<label>` связывает текстовое описание с элементом формы, улучшая доступность и удобство использования. При клике на `<label>` фокус переходит на связанный элемент. Связь устанавливается атрибутом `for`, совпадающим с `id` инпута, либо вложением инпута внутрь самого `<label>`.

```html
<!-- Через атрибут for -->
<label for="email">Email:</label>
<input type="email" id="email" name="email" />

<!-- Через вложение -->
<label>
  Пароль:
  <input type="password" name="password" />
</label>
```

## Чем отличается элемент от тега?

**Тег** — синтаксическая конструкция в HTML-документе: `<p>`, `</p>`, `<img />`. Тег — это разметка в исходном коде.

**Элемент** — объект в памяти (узел DOM), который браузер создаёт на основе разбора HTML. У элемента есть свойства, методы и события.

```html
<!-- Теги — текст в HTML -->
<p class="intro">Hello</p>
```

```javascript
// Элемент — DOM-объект в JS
const el = document.querySelector('.intro');
el.textContent;    // 'Hello'
el.style.color = 'red';
el.addEventListener('click', fn);
```

Один HTML-тег порождает один DOM-элемент. Но DOM содержит не только элементы (теги), но и текстовые узлы, комментарии.

## Виды списков в HTML?

| Тег | Тип | Маркер |
|---|---|---|
| `<ul>` | Неупорядоченный | буллет (•) |
| `<ol>` | Упорядоченный | цифры (1, 2, 3) |
| `<dl>` | Список описаний | термин + описание |

```html
<!-- Неупорядоченный -->
<ul>
  <li>Хлеб</li>
  <li>Молоко</li>
</ul>

<!-- Упорядоченный: type, start, reversed -->
<ol type="A" start="3">
  <li>Третий</li>
  <li>Четвёртый</li>
</ol>

<!-- Список описаний -->
<dl>
  <dt>HTML</dt>
  <dd>Язык разметки страниц</dd>
  <dt>CSS</dt>
  <dd>Язык стилей</dd>
</dl>
```

Стиль маркера/нумерации меняется через `list-style-type`, `list-style-image`, `list-style-position` или `counter-reset`/`counter-increment` для кастомной нумерации.

## Якоря и ссылки в HTML?

**Ссылка** (`<a href>`) может вести на: другую страницу, раздел на странице (якорь), email, телефон, файл.

```html
<!-- Внешняя ссылка -->
<a href="https://example.com" target="_blank" rel="noopener noreferrer">Site</a>

<!-- Внутренняя ссылка -->
<a href="/about">О нас</a>

<!-- Якорь (цель) — по id элемента -->
<a href="#section2">Перейти к разделу 2</a>
<!-- цель: -->
<h2 id="section2">Раздел 2</h2>

<!-- Якорь на другой странице -->
<a href="/page#section">Раздел на другой странице</a>

<!-- Email и телефон -->
<a href="mailto:me@example.com">Написать</a>
<a href="tel:+79001234567">Позвонить</a>

<!-- Скачать файл -->
<a href="/file.pdf" download="report">PDF</a>
```

**`target` атрибут:** `_self` (текущая вкладка), `_blank` (новая). Всегда сочетай `_blank` с `rel="noopener noreferrer"` — защита от **reverse tabnapping** (новая вкладка может изменить `window.opener`).

## Спецсимволы в HTML?

Спецсимволы (называются HTML entities) представляют символы, которые нельзя напрямую вставить в HTML или нужно отобразить символ. Формат: `&name;` или `&#code;`.

| Entity | Символ | Описание |
|---|---|---|
| `&nbsp;` |   | Неразрывный пробел |
| `&lt;` | < | Меньше |
| `&gt;` | > | Больше |
| `&amp;` | & | Амперсанд |
| `&quot;` | " | Кавычка |
| `&apos;` | ' | Апостроф |
| `&copy;` | © | Авторское право |
| `&reg;` | ® | Зарегистрированный товарный знак |
| `&mdash;` | — | Тире |
| `&laquo;` `&raquo;` | « » | Гильошеты |
| `&#128512;` | 😀 | Unicode эмоджи |

## Почему стили помещают в head, а скрипты перед /body?

**CSS в `<head>`:** браузер не начинает рендеринг страницы, пока не построен CSSOM. Если поместить CSS после `<body>` — пользователь увидит нестилизованный HTML (мелькание FOUC — Flash of Unstyled Content).

**JS перед `</body>`:** обычный `<script>` **блокирует** парсинг HTML. Если поместить скрипт в `<head>` без `defer`/`async` — DOM ещё не готов и скрипт не найдёт элементы.

```html
<head>
  <!-- CSS — здесь, чтобы не было FOUC -->
  <link rel="stylesheet" href="styles.css">

  <!-- Скрипты в head: только с defer или async -->
  <script defer src="app.js"></script>
  <!-- defer: загрузка параллельно, выполнение после DOM -->
  <!-- async: загрузка параллельно, выполнение сразу -->
</head>
<body>
  ...
  <!-- Старый подход: без defer -->
  <script src="app.js"></script>
</body>
```
