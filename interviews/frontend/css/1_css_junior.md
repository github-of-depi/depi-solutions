## Что такое блочная модель (box model)?

Каждый элемент — прямоугольник из слоёв: content → padding → border → margin. `box-sizing: border-box` включает padding и border в объявленные width/height (по умолчанию content-box — padding прибавляется к размеру). В современных проектах `border-box` — стандарт.

## Как работает Flexbox?

Flexbox — одномерная система раскладки. Контейнер (`display: flex`) управляет расположением детей по главной оси (`flex-direction`) и поперечной. Ключевые свойства: `justify-content` (главная ось), `align-items` (поперечная), `flex-wrap`, `gap`. Дети управляются через `flex-grow`, `flex-shrink`, `flex-basis`.

```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
.item { flex: 1; } /* grow:1 shrink:1 basis:0 */
```

## Что такое специфичность (specificity) CSS?

Специфичность определяет, какое правило применяется при конфликте. Рассчитывается как (a, b, c): a — inline styles, b — id селекторы, c — классы/атрибуты/псевдоклассы. Тег — наименее специфичный. `!important` перебивает всё (избегать).

```css
#id .class tag    /* (0,1,1,1) */
.class            /* (0,0,1,0) */
tag               /* (0,0,0,1) */
```

## Что такое каскад в CSS?

Каскад — алгоритм определения применяемого стиля при конфликте. Порядок приоритетов: происхождение (browser < user < author), важность (`!important`), специфичность, порядок объявления (последнее выигрывает).

## Чем em отличается от rem?

`em` — относительно font-size ближайшего родителя. `rem` — относительно font-size корневого элемента (`html`). `rem` предпочтительнее для консистентных размеров, `em` полезен когда нужна зависимость от родителя (padding, margin кнопки).

## Что такое псевдоклассы и псевдоэлементы?

**Псевдоклассы** (`:hover`, `:focus`, `:first-child`, `:nth-child`) — состояние элемента. **Псевдоэлементы** (`::before`, `::after`, `::placeholder`) — виртуальные части элемента. Псевдоэлементы записываются с двумя двоеточиями.

```css
a:hover { color: blue; }
input:focus { outline: 2px solid blue; }
p::first-line { font-weight: bold; }
.icon::before { content: "→"; }
```

## Типы позиционирования в CSS?

CSS-свойство `position` определяет способ размещения элемента в документе:

- **`static`** — стандартный поток, `top`/`left` не работают (значение по умолчанию)
- **`relative`** — элемент остаётся в потоке, но смещается относительно своей нормальной позиции
- **`absolute`** — выбывает из потока, позиционируется относительно ближайшего предка с `position` ≠ `static`
- **`fixed`** — выбывает из потока, позиционируется относительно viewport; остаётся на месте при прокрутке
- **`sticky`** — гибрид: ведёт себя как `relative` до достижения порогового значения `top`/`left`, затем «прилипает» как `fixed`

```css
/* Классический паттерн: родитель relative + ребёнок absolute */
.tooltip-wrapper { position: relative; }
.tooltip { position: absolute; bottom: 100%; left: 0; }

/* Sticky-заголовок таблицы */
thead th { position: sticky; top: 0; background: white; }
```

## Разница между display: none, visibility: hidden и opacity: 0?

Все три скрывают элемент визуально, но ведут себя по-разному:

| Свойство | В документе | Доступно скринридеру | Кликабельно |
|---|---|---|---|
| `display: none` | Нет | Нет | Нет |
| `visibility: hidden` | Да (место занято) | Нет | Нет |
| `opacity: 0` | Да (место занято) | Да | Да |

`display: none` полностью убирает элемент из рендер-дерева. `visibility: hidden` сохраняет занятое место. `opacity: 0` оставляет элемент полностью интерактивным — по нему можно кликнуть, он остаётся в потоке и доступен для вспомогательных технологий.

```css
/* opacity: 0 — элемент невидим, но перехватывает клики */
.overlay { opacity: 0; pointer-events: none; } /* нужен pointer-events: none */
```
