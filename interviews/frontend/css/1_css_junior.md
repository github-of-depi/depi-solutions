## Что такое блочная модель (box model)?

Каждый элемент — прямоугольник из слоёв: content → padding → border → margin. `box-sizing: border-box` включает padding и border в объявленные width/height (по умолчанию content-box — padding прибавляется к размеру). В современных проектах `border-box` — стандарт.

## Как работает Flexbox?

Flexbox — одномерная система раскладки. Контейнер (`display: flex`) управляет расположением детей по главной оси (`flex-direction`) и поперечной. Ключевые свойства: `justify-content` (главная ось), `align-items` (поперечная), `flex-wrap`, `gap`. Дети управляются через `flex-grow`, `flex-shrink`, `flex-basis`.

```css
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 16px;
}
.item { flex: 1; } /* grow:1 shrink:1 basis:0 */
```

## Что такое специфичность (specificity) CSS?

Специфичность определяет, какое правило применяется при конфликте. Рассчитывается как (a, b, c): a — inline styles, b — id селекторы, c — классы/атрибуты/псевдоклассы. Тег — наименее специфичный. `!important` перебивает всё (избегать).

```css
#id .class tag    /* (0,1,1,1) */
.class            /* (0,0,1,0) */
tag               /* (0,0,0,1) */
```

## Чем em отличается от rem?

`em` — относительно font-size ближайшего родителя. `rem` — относительно font-size корневого элемента (`html`). `rem` предпочтительнее для консистентных размеров, `em` полезен когда нужна зависимость от родителя (padding, margin кнопки).

## Что такое псевдоклассы и псевдоэлементы?

**Псевдоклассы** (`:hover`, `:focus`, `:first-child`, `:nth-child`) — состояние элемента. **Псевдоэлементы** (`::before`, `::after`, `::placeholder`) — виртуальные части элемента. Псевдоэлементы записываются с двумя двоеточиями.

```css
a:hover { color: blue; }
input:focus { outline: 2px solid blue; }
p::first-line { font-weight: bold; }
.icon::before { content: "→"; }
```

## Типы позиционирования в CSS?

CSS-свойство `position` определяет способ размещения элемента в документе:

- **`static`** — стандартный поток, `top`/`left` не работают (значение по умолчанию)
- **`relative`** — элемент остаётся в потоке, но смещается относительно своей нормальной позиции
- **`absolute`** — выбывает из потока, позиционируется относительно ближайшего предка с `position` ≠ `static`
- **`fixed`** — выбывает из потока, позиционируется относительно viewport; остаётся на месте при прокрутке
- **`sticky`** — гибрид: ведёт себя как `relative` до достижения порогового значения `top`/`left`, затем «прилипает» как `fixed`

```css
/* Классический паттерн: родитель relative + ребёнок absolute */
.tooltip-wrapper { position: relative; }
.tooltip { position: absolute; bottom: 100%; left: 0; }

/* Sticky-заголовок таблицы */
thead th { position: sticky; top: 0; background: white; }
```

## Разница между display: none, visibility: hidden и opacity: 0?

Все три скрывают элемент визуально, но ведут себя по-разному:

| Свойство | В документе | Доступно скринридеру | Кликабельно |
|---|---|---|---|
| `display: none` | Нет | Нет | Нет |
| `visibility: hidden` | Да (место занято) | Нет | Нет |
| `opacity: 0` | Да (место занято) | Да | Да |

`display: none` полностью убирает элемент из рендер-дерева. `visibility: hidden` сохраняет занятое место. `opacity: 0` оставляет элемент полностью интерактивным — по нему можно кликнуть, он остаётся в потоке и доступен для вспомогательных технологий.

```css
/* opacity: 0 — элемент невидим, но перехватывает клики */
.overlay { opacity: 0; pointer-events: none; } /* нужен pointer-events: none */
```

## Reset и Normalize CSS — в чём разница?

Браузеры применяют дефолтные стили, которые отличаются. Для единообразия есть два подхода:

| | **CSS Reset** | **Normalize.css** |
|---|---|---|
| Цель | Стриш все стили | Сделать одинаковыми |
| Подход | Обнулить всё до 0 | Сохранить полезные дефолты |
| Результат | Больше пишеть стили | Меньше CSS |
| Пример | Eric Meyer Reset | Normalize.css |

```css
/* CSS Reset (Eric Meyer style) */
*, *::before, *::after { box-sizing: border-box; }
body, h1, h2, p, ul, ol { margin: 0; padding: 0; }
ul, ol { list-style: none; }
img { max-width: 100%; display: block; }

/* Современный CSS Reset (из Tailwind) */
*, *::before, *::after { box-sizing: border-box; }
* { margin: 0; }
```

## CSS-трансформации (transform)?

`transform` — CSS-свойство для геометрических преобразований. Не вызывает reflow — работает на уровне композитинга (GPU-акселерация).

```css
/* Основные функции */
.el {
  transform: translate(50px, 20px);  /* сдвиг */
  transform: translateX(50px);
  transform: scale(1.2);             /* масштабирование */
  transform: rotate(45deg);          /* поворот */
  transform: skew(10deg, 5deg);      /* искажение */
  transform: scaleX(-1);             /* зеркальное отображение */

  /* Комбинация */
  transform: rotate(30deg) scale(1.1) translateX(10px);

  /* Точка отсчёта */
  transform-origin: top left; /* default: center */
}

/* 3D */
.el3d {
  transform: rotateY(180deg);
  perspective: 500px;
  backface-visibility: hidden;
}

/* Центрирование элемента (популярный паттерн) */
.center {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}
```

## @import в CSS?

`@import` позволяет включать один CSS-файл в другой. **Недостаток:** блокирующая загрузка — браузер загружает файлы последовательно, а не параллельно.

```css
/* В CSS-файле — должно быть в начале */
@import url('variables.css');
@import url('typography.css');
@import url('components.css') screen and (min-width: 768px);

/* В SCSS/Sass @import частью заменили @use и @forward */
```

**Предпочтительнее:** `<link rel="stylesheet">` ␲ параллельная загрузка, или бандлер (Vite/Webpack) для оптимизации.

## Наследование в CSS?

**Наследуемые** свойства передаются дочерним элементам. **Ненаследуемые** — нет.

**Наследуемые:** `color`, `font-*`, `line-height`, `letter-spacing`, `text-*`, `cursor`, `visibility`, `list-style`

**Ненаследуемые:** `width`, `height`, `margin`, `padding`, `border`, `background`, `position`, `display`, `flex`

```css
.parent { color: blue; width: 200px; }
```

```html
<div class="parent">
  <p>Этот текст будет синим</p> <!-- color наследуется -->
  <!-- но width: 200px не наследуется -->
</div>
```

`inherit` — явно наследовать. `initial` — браузерный дефолт. `unset` — `inherit` если наследуется, иначе `initial`. `revert` — браузерный стиль по умолчанию.

## Комбинаторы CSS?

```css
/* Потомок (space) — любой потомок */
.parent .child { color: red; }

/* Дочерний (>) — прямой родитель */
.parent > .child { color: blue; }

/* Смежный (+) — следующий сосед */
h2 + p { margin-top: 0; }

/* Общий (~) — все следующие соседи */
h2 ~ p { color: gray; }

/* Групповой (,) — несколько селекторов */
h1, h2, h3 { font-weight: bold; }
```

## Float и clear?

`float` вытащивает элемент влево/вправо и обтекает его остальный контент. `clear` отменяет обтекание.

```css
.image { float: left; margin-right: 16px; }
.text  { /* обтекает float-элемент */ }

.footer { clear: both; } /* не обтекать float слева и справа */

/* clearfix: контейнер с float-детьми схлопывается в 0 */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}
```

Сейчас float используют только для обтекания текстом картинок. Для разметки — flexbox/grid.

## Block, inline, inline-block — разница?

| | `block` | `inline` | `inline-block` |
|---|---|---|---|
| Новая строка | да | нет | нет |
| Ширина | 100% родителя | по контенту | по контенту |
| width/height | да | нет | да |
| margin/padding | все стороны | только гориз. | все стороны |
| Примеры | `div`, `p`, `h1` | `span`, `a`, `strong` | `button`, `img` |

```css
span { display: block; }        /* стал блочным */
div  { display: inline-block; } /* в строку, но с размерами */
```

## Способы подключения стилей?

1. **`<link rel="stylesheet">`** — внешний файл, рекомендуемый способ
2. **`<style>`** в `<head>` — встроенные стили
3. **`style="..."`** атрибут элемента — инлайновые стили
4. **`@import`** в CSS-файле — включение другого файла
5. **JS** `document.styleSheets`, `el.style.color = '...'`
6. **CSS-in-JS** (styled-components, Emotion)

```html
<!-- 1. Внешний файл (в head) -->
<link rel="stylesheet" href="styles.css">

<!-- 2. Встроенный -->
<style>body { margin: 0; }</style>

<!-- 3. Инлайновый -->
<p style="color: red">Текст</p>
```

## Единицы измерения CSS?

| Единица | На чём базируется |
|---|---|
| `px` | Пиксель экрана (абсолютная) |
| `%` | От родительского элемента |
| `em` | От font-size родителя |
| `rem` | От font-size `:root` (html) |
| `vw` | 1% ширины вьюпорта |
| `vh` | 1% высоты вьюпорта |
| `vmin` / `vmax` | Меньшая / большая сторона viewport |
| `fr` | Доль свободного пространства (grid) |
| `ch` | Ширина символа `0` |
| `pt`, `cm`, `mm` | Печать, редко в вебе |

```css
:root { font-size: 16px; }

.container { max-width: 80vw; }
.text      { font-size: 1.125rem; } /* 18px */
.padding   { padding: 1em; }        /* = font-size элемента */
.grid      { grid-template-columns: 1fr 2fr 1fr; }
```

## Как обрезать длинный текст?

```css
/* Одна строчка с многоточием */
.truncate {
  white-space: nowrap;      /* не переносить на новую строку */
  overflow: hidden;         /* обрезать */
  text-overflow: ellipsis;  /* ... */
}

/* Многострочный обрез (-webkit-line-clamp) */
.clamp {
  display: -webkit-box;
  -webkit-line-clamp: 3;     /* количество строк */
  -webkit-box-orient: vertical;
  overflow: hidden;
  /* line-clamp: 3; */ /* современный стандарт */
}
```

## Инлайновые стили?

`style` атрибут на элементе. Имеют наивысшую специфичность (1000+), перебивают любые CSS-правила кроме `!important`.

**Когда использовать:**
- Динамические стили, вычисляемые в JS (React `style={{width}}`, анимации)
- Стронние библиотеки (UI-kit иньекция стилей)

**Недостатки:**
- Нет псевдоэлементов (`::before`)
- Сложно переопределить из CSS
- Нет поддержки media queries
- Засоряет CSS-кэш
