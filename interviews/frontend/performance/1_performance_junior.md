## Что такое Web Vitals?

Web Vitals — метрики Google для измерения пользовательского опыта: скорость загрузки, интерактивность, визуальная стабильность. Core Web Vitals: LCP, INP, CLS — влияют на SEO-ранжирование. Измеряются в Chrome DevTools, PageSpeed Insights, Lighthouse.

## Что такое LCP, FID/INP и CLS?

- **LCP** (Largest Contentful Paint) — время до отрисовки наибольшего видимого элемента. Хорошо: < 2.5с.
- **INP** (Interaction to Next Paint, заменил FID) — задержка реакции на взаимодействия. Хорошо: < 200мс.
- **CLS** (Cumulative Layout Shift) — нестабильность раскладки при загрузке. Хорошо: < 0.1.

## Что такое lazy loading и зачем он нужен?

Lazy loading — загрузка ресурсов только когда они нужны. Для изображений: `loading="lazy"` — браузер загружает только при приближении к viewport. Для кода: `React.lazy` / `import()` — загружает JavaScript модуль при необходимости. Уменьшает initial load time.

## Зачем оптимизировать размер JavaScript бандла?

Больший JS бандл = дольше загрузка (особенно на мобильных/медленном соединении), дольше парсинг и компиляция JS движком. Каждый КБ JS стоит дороже, чем КБ изображения — JS блокирует main thread.

## Что такое кэширование в браузере?

Браузер сохраняет ресурсы локально на основе HTTP-заголовков: `Cache-Control: max-age=31536000` — кэшировать год (для статики с hash в имени), `no-cache` — проверять на сервере каждый раз, `no-store` — не кэшировать. Service Worker позволяет управлять кэшем программно.
