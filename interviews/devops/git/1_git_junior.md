## Что такое Git и зачем он нужен?

Git — распределённая система контроля версий. Хранит историю изменений, позволяет ветвление и слияние, совместная работа. Каждый разработчик имеет полную копию репозитория.

---

## Основные команды Git?

```bash
git clone <url>          # клонировать репозиторий
git add .                # добавить все изменения в staging
git commit -m "message"  # создать коммит
git push origin main     # отправить на remote
git pull                 # получить обновления
git status               # статус файлов
git log --oneline        # история коммитов
```

---

## Что такое branch и как с ним работать?

Branch — параллельная линия разработки. Feature branches: новая фича → отдельная ветка → PR → merge в main.

```bash
git checkout -b feature/user-profile  # создать и переключиться
git push origin feature/user-profile  # отправить на remote
git checkout main                     # вернуться
git branch -d feature/user-profile   # удалить локально
```

---

## Что такое merge и rebase?

**merge**: объединяет две ветки, создаёт merge commit. История нелинейная, сохраняет контекст. **rebase**: переносит коммиты поверх другой ветки. История линейная, чище. Правило: не rebase публичных веток (меняет историю).

---

## Что такое .gitignore?

`.gitignore` — список файлов/папок, которые git не отслеживает. `node_modules/`, `.env`, `dist/`, `.DS_Store`. Не добавлять секреты в репозиторий никогда.
