## Что такое Feature-Sliced Design?

FSD — методология архитектуры фронтенда. Разделяет код по бизнес-смыслу (фичам, сущностям), а не по техническому типу (components, utils). Цель: управляемость, масштабируемость, низкая связанность.

---

## Какие слои есть в FSD?

Слои (сверху вниз, могут импортировать только нижние):

| Слой | Что содержит |
|------|-------------|
| `app` | Инициализация, провайдеры, роутинг |
| `pages` | Страницы приложения |
| `widgets` | Самостоятельные блоки UI |
| `features` | Бизнес-фичи (действия пользователя) |
| `entities` | Бизнес-сущности (User, Product) |
| `shared` | Переиспользуемое (UI kit, utils, API) |

---

## Что такое slice и segment в FSD?

**Slice** — именованная единица внутри слоя (например, `entities/user`, `features/auth`). **Segment** — техническое разделение внутри slice: `ui/`, `model/`, `api/`, `lib/`, `config/`. Публичный API через `index.ts`.

---

## Какое правило импортов в FSD?

Строгое правило: слой может импортировать только из слоёв **ниже** себя. `features` не импортирует из `pages`. Внутри слоя: slice не импортирует другой slice того же слоя (только `shared`). Нарушения ловит eslint-plugin-fsd.
