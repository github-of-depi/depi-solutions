## Что такое micro-frontends?

Micro-frontends — архитектурный подход, где фронтенд приложение разбивается на независимые части (micro-apps). Каждая команда владеет своей частью end-to-end (бэкенд + фронтенд). Аналог микросервисов для фронтенда.

## Какие проблемы решают micro-frontends?

- Независимый деплой разных частей приложения
- Разные команды без координации (feature teams)
- Постепенная миграция legacy приложения
- Масштабирование разработки (100+ разработчиков)

Недостатки: сложность настройки, дублирование зависимостей, UX несогласованность.

## Что такое Module Federation?

Module Federation (Webpack 5) — механизм загрузки кода из других bundled приложений в runtime. Host приложение подключает remote (micro-frontend) как обычный импорт.
