## Что проверять при code review?

Базовый чеклист:
- Код работает (выполняет задачу)
- Понятны имена переменных/функций
- Нет очевидного дублирования
- Есть тесты для нетривиальной логики
- Нет секретов и sensitive данных в коде

---

## Как давать конструктивный фидбек?

1. **Задавать вопросы** вместо утверждений: "Почему выбрано X?" не "Это неправильно"
2. **Конкретно**: "Эту функцию можно разбить на X и Y" не "Слишком сложно"
3. **Различать**: блокер (нужно исправить) vs suggestion (можно рассмотреть)
4. **Хвалить** хорошее решение
5. **Объяснять** почему, не только что

---

## Как воспринимать фидбек на свой код?

Фидбек — про код, не про тебя. Задавать уточняющие вопросы если непонятно. Не защищаться автоматически — рассмотреть точку зрения. Если не согласен — аргументированно возразить. Отмечать комментарии как "разобрано".
