## Что такое доступность (accessibility)?

A11y — возможность использовать сайт людьми с ограниченными возможностями: зрение (screen readers), слух (субтитры), моторика (клавиатура вместо мыши), когнитивные. Также юридическое требование (ADA, EAA).

## Что такое WCAG?

## Что такое ARIA?

ARIA (Accessible Rich Internet Applications) — атрибуты для добавления семантики интерактивным элементам. Правило #1: используй нативные HTML элементы. ARIA — когда нативного нет.

```html
<!-- Нативный — лучше -->
<button>Отправить</button>

<!-- ARIA когда нет нативного -->
<div role="button" aria-pressed="false" tabindex="0">Отправить</div>
```

## Что такое alt текст и когда он нужен?

`alt` — описание изображения для screen readers. Информативные изображения: `alt="График роста продаж за 2024"`. Декоративные: `alt=""` (пустой, не `alt="photo"`). Кнопки-иконки: `aria-label` вместо alt.

## В чём разница между accessibility и usability?

**Usability** (удобство использования) — насколько легко и эффективно *любой* пользователь может достичь цели. **Accessibility** (доступность) — возможность использовать интерфейс *людьми с ограниченными возможностями* (зрение, слух, моторика, когниция).

Ключевое отличие: usability затрагивает весь UX, accessibility — специфическая часть о включении. Хорошо спроектированный доступный сайт, как правило, удобнее для всех: субтитры помогают не только глухим, крупные кнопки — не только людям с нарушениями моторики.

## Что такое скринридер и как он работает?

Скринридер — вспомогательная технология, которая читает содержимое экрана вслух для людей с нарушениями зрения. Он обходит accessibility tree браузера (построенный на основе DOM + ARIA-атрибутов) и озвучивает каждый элемент: роль, имя, состояние.

Популярные скринридеры: **NVDA** (Windows, бесплатный) + Chrome, **JAWS** (Windows, платный) + Chrome/Edge, **VoiceOver** (macOS/iOS, встроенный) + Safari, **TalkBack** (Android) + Chrome.

Разработчику важно знать: порядок чтения соответствует DOM-порядку; `display:none` / `visibility:hidden` убирают элемент из accessibility tree; `aria-hidden="true"` скрывает его явно, не убирая визуально.

## Как скрыть элемент от скринридеров и как сделать его видимым только для них?

**Скрыть от скринридера** (декоративный контент, иконки-дубли):

```html
<!-- aria-hidden — убирает из accessibility tree, остаётся видимым -->
<span aria-hidden="true">★</span>

<!-- display:none/visibility:hidden — скрывает и визуально, и от скринридера -->
<div style="display:none">Скрыто полностью</div>
```

**Видимо только скринридеру** (visually-hidden / sr-only):

```css
.sr-only {
  position: absolute;
  width: 1px;
  height: 1px;
  padding: 0;
  margin: -1px;
  overflow: hidden;
  clip: rect(0, 0, 0, 0);
  white-space: nowrap;
  border: 0;
}
```

```html
<button>
  <svg aria-hidden="true">...</svg>
  <span class="sr-only">Удалить запись</span>
</button>
```

## Как удалить семантику у HTML-элемента?

`role="none"` (синоним: `role="presentation"`) убирает встроенную семантическую роль элемента из accessibility tree. Используется, когда нативный тег применяется только для визуальной раскладки без семантического значения.

```html
<!-- Таблица только для раскладки — убираем семантику таблицы -->
<table role="presentation">
  <tr><td>Левый блок</td><td>Правый блок</td></tr>
</table>
```

> **Важно**: `role="none"` не убирает элемент из accessibility tree полностью — текстовое содержимое по-прежнему читается. Для полного скрытия используй `aria-hidden="true"`.

## Что такое skip-links?

Skip-link — скрытая ссылка в начале страницы, позволяющая пользователям клавиатуры и скринридеров пропустить повторяющуюся навигацию и сразу перейти к основному контенту. Требование WCAG 2.4.1 (уровень A).

```html
<a href="#main-content" class="skip-link">Перейти к основному содержимому</a>
<nav>...</nav>
<main id="main-content" tabindex="-1">...</main>
```

```css
.skip-link {
  position: absolute;
  top: -100%;
  left: 0;
  background: #000;
  color: #fff;
  padding: 8px 16px;
  z-index: 9999;
}
.skip-link:focus { top: 0; } /* Показываем только при фокусе */
```

`tabindex="-1"` на `<main>` нужен, чтобы элемент принял программный фокус (он не интерактивный по умолчанию).
