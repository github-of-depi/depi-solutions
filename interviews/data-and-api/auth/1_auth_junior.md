## В чём разница между аутентификацией и авторизацией?

**Аутентификация** — подтверждение личности (кто ты?). **Авторизация** — проверка прав (что тебе можно?). Сначала аутентификация, затем авторизация.

## Что такое JWT?

JWT (JSON Web Token) — токен из трёх частей: header.payload.signature, закодированных base64url. Payload содержит claims (id, email, role, exp). Signature проверяет целостность. Stateless — сервер не хранит сессию. Не шифруется (только подписывается) — не хранить секреты в payload.

## Где хранить токен аутентификации?

- **httpOnly Cookie** — недоступна JS, защита от XSS. Уязвима к CSRF (но есть SameSite защита).
- **localStorage** — доступна JS, уязвима к XSS.
- **In-memory** — самая безопасная, теряется при обновлении страницы.

Рекомендация: httpOnly cookie для refresh token + in-memory для access token.

## Что такое сессии на основе cookie?

Сервер создаёт сессию, хранит в памяти/Redis, отдаёт клиенту ID сессии через httpOnly cookie. Stateful — сервер знает о каждой сессии. Легко инвалидировать (удалить сессию). Проблема при горизонтальном масштабировании.

## Что такое OAuth2?

OAuth2 — протокол авторизации для делегирования доступа. «Войти через Google/GitHub» — OAuth2. Клиент получает access token от authorization server, предъявляет resource server. Не аутентификация (для этого OpenID Connect).
